What Is an ADK Agent?

Google ADK explained from zero: the five things every agent is made of

ADK in one sentence

Google ADK is a toolkit that turns an LLM into an agent: an AI that can look things up and work toward a goal, not just chat.

Think of hiring a new employee. A smart graduate (the model) is useless on day one without an onboarding kit. ADK is that kit.

🧠

model

Which brain they use: Gemini, or Qwen on your own vLLM server.

📜

instruction

The job description: "You are the Triage agent. Decide severity…"

🔑

tools

The keycards: which systems they may look at (SIEM, AD…).

🗂️

output_schema

The form they must fill in: fixed boxes such as severity and users.

📥

output_key

The out-tray: where they drop the filled form for the next person.

A real agent, line by line

This is the actual Triage agent. Every agent in the project looks like this.

CODE · soc_agents/triage/agent.py 
def build_triage_agent() -> LlmAgent:
    return LlmAgent(
        name="triage",
        description="First look at a SOC alert: severity, entities, time window, what to investigate.",
        model=get_model("pro"),
        static_instruction=STATIC,  # fixed rules: cache-friendly system prompt
        tools=[
            mcp_tools("siem_mcp", ["get_alert", "get_events", "list_alerts"]),
            mcp_tools("edr_read_mcp", ["get_events"]),
            mcp_tools("ad_mcp", ["get_user", "get_host"]),
            mcp_tools("case_mcp", ["get_case", "search_changes"]),
        ],
        include_contents="none",  # inputs come via {state} in the instruction, not chat history
        output_schema=TriageResult,
        output_key="triage",
        before_tool_callback=guarded(8),
        before_model_callback=shared_system_prompt,
    )
PLAIN ENGLISH

A recipe that builds the Triage agent.

Create a thinking agent (LlmAgent = "an agent with a model inside").

Its name tag is "triage".

A one-line summary of its job.

Use the strongest model tier ("pro").

Its job description, which never changes between runs.

The systems it may look at:

the SIEM: only these 3 lookups,

the EDR: only fetching events,

Active Directory: only user and PC lookups,

the case system: only case details and change records.

(end of the tool list)

Don't re-read the whole chat history: cheaper and faster.

The answer must fit the TriageResult form.

Save the answer on the shared notepad under the label "triage".

Before every tool use, run the safety checks (max 8 tool calls).

Before every model call, tidy the prompt (more in Module 5).

(done)

💡
An agent is mostly configuration

Notice there's no "how to investigate" logic in this code. The thinking happens inside the model. Your code only sets what it knows, what it may touch, and what shape its answer takes. That's why you change agent behaviour by editing prompt.py, not by writing new code.

Four kinds of agent in this project

Not every "agent" in ADK thinks. Some are just managers that decide who works when.

🧠

LlmAgent

Has a model and thinks. Triage, the 4 specialists, Investigator, Planner.

🏭

SequentialAgent

An assembly line: runs its sub-agents one after another, always in the same order.

🏎️

ParallelAgent

A pit crew: all sub-agents work at the same time. Used for the 4 specialists.

⚙️

BaseAgent (custom)

Plain code dressed as an agent. The Reporter fills a ticket template, no AI.

Swapping the brain: Gemini or your own server

The agents never name a specific model. They ask for a tier ("pro" for hard thinking, "flash" for quick work), and one small function decides which model that means, using settings in the .env file.

CODE · soc_agents/common/models.py 
def get_model(tier: str) -> str | BaseLlm:
    """Model for a tier: 'pro' (reasoning), 'flash' (specialists), 'lite' (guard/judge)."""
    provider = os.environ.get("SOC_MODEL_PROVIDER", "vllm").lower()
    if provider == "vllm":
        model = os.environ.get(f"VLLM_MODEL_{tier.upper()}") or os.environ.get("VLLM_MODEL")
PLAIN ENGLISH

"Give me the model for this tier."

(A note explaining the three tiers.)

Read SOC_MODEL_PROVIDER from the settings; if it's missing, assume vllm.

If it's the local vLLM server…

…use the tier-specific model if one is set, otherwise the general VLLM_MODEL.

SOC_MODEL_PROVIDER=vllmUse your own vLLM server: no quota, data stays local
SOC_MODEL_PROVIDER=geminiUse Google's Gemini with an API key: easy, but the free tier is limited
